# Blog posts

One post per finished study, newest first. Each post states one rule of training, the runs that test it and how well it predicts runs it never saw. How a post is written and when a study counts as finished: [agents/focused-persistence.md](../agents/focused-persistence.md).

A post may live in this folder (`blog/<yyyy-mm-dd>-<slug>/README.md`) or somewhere else; either way it gets a line here. The runs for every post are on Hugging Face at [vukrosic/training-laws-research](https://huggingface.co/datasets/vukrosic/training-laws-research) under `studies/<slug>/`.
